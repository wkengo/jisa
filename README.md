# 世界時差時計（GitHub Pages版）

## 公開方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダー内の `index.html` をリポジトリ直下へアップロードします。
3. リポジトリの「Settings」→「Pages」を開きます。
4. 「Build and deployment」のSourceを「Deploy from a branch」にします。
5. Branchを `main`、フォルダーを `/(root)` にして保存します。

サーバー処理や外部APIは不要です。登録地域と現在地設定はブラウザーのlocalStorageに保存されます。
